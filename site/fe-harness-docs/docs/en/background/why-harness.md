# Why fe-harness

## Problem

Frontend projects often face these challenges:

1. **Inconsistent Quality**: Different teams use different standards
2. **Manual Processes**: Repetitive tasks done manually
3. **Knowledge Silos**: Best practices not shared across teams
4. **Agent Unreadiness**: Projects not structured for AI assistance

## Solution

fe-harness provides:

### 1. Business-Agnostic Foundation

- No hardcoded business logic
- No hardcoded API endpoints or tokens
- Reusable across projects and teams

### 2. Configuration-Driven Verification

- Quick, Feature, Visual, Audit modes
- Automatic test generation
- Comprehensive reporting

### 3. Agent-First Design

- Structured project facts
- Clear input/output contracts
- Skill-based workflows

### 4. Evidence-Based Workflow

- All decisions backed by documented inputs
- PRD/RP/UI/API as contract
- Versioned snapshots

## Principles

- **Business-neutral by default**
- **Project-owned configuration**
- **Evidence-first decision making**
- **Agent-friendly structure**
